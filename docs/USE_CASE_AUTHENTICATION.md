# Use Case Specifications - Authentication Module

## UC01 - Login

| Section               | Content                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **UC ID and Name**    | UC01 Login                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Created By**        | Le Thanh Tra                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Date Created**      | 26/01/2026                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Primary Actor**     | Customer/User                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Secondary Actors**  | None                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Trigger**           | The User wants to log in to the system to use UniLife features.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Description**       | This Use Case allows the User to log in to the system using their registered email and password. After successful login, the User will receive an access token to authenticate subsequent requests.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **Preconditions**     | • The login page is displayed.<br>• The User has an account in the system.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Postconditions**    | • The User is authenticated and logged into the system.<br>• The access token is saved to localStorage.<br>• User information is saved to localStorage.<br>• The User is redirected to the home page.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Normal Flow**       | 1. The User accesses the login page.<br>2. The User enters email in the "Email" field.<br>3. The User enters password in the "Mật khẩu" field.<br>4. The User clicks the "Đăng nhập" button.<br>5. The system validates the login credentials.<br>6. The system generates an access token and returns user information.<br>7. The system displays message "Đăng nhập thành công".<br>8. The system redirects the user to the home page.                                                                                                                                                                                                                                                                                                                                                                                    |
| **Alternative Flows** | **A. Incorrect email or password (Step 5)**<br>A.1 The system cannot find user with the email or password does not match.<br>A.2 The system displays message "Email hoặc mật khẩu sai".<br>A.3 The User can re-enter information and try again.<br>A.4 Return to Step 2.<br><br>**B. Missing login information (Step 4)**<br>B.1 The User has not entered email or password.<br>B.2 The system displays message requesting complete information.<br>B.3 Return to Step 2.<br><br>**C. User forgot password (Step 3)**<br>C.1 The User clicks "Quên mật khẩu?" link.<br>C.2 The system redirects to the forgot password page.<br>C.3 End Use Case.<br><br>**D. User does not have account (Step 1)**<br>D.1 The User clicks "Đăng ký ngay" link.<br>D.2 The system redirects to the registration page.<br>D.3 End Use Case. |
| **Exceptions**        | **E. Network connection lost (Step 5)**<br>E.1 Network connection is interrupted while sending login request.<br>E.2 The system displays network error message.<br>E.3 End Use Case.<br><br>**F. Unknown system error (Step 5 or Step 6)**<br>F.1 An unexpected system error occurs.<br>F.2 The system logs the error.<br>F.3 The system displays generic error message.<br>F.4 End Use Case.                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Priority**          | High, Must Have                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Frequency of Use**  | Very frequent                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Business Rules**    | • Email must be in valid email format.<br>• Password must be at least 6 characters.<br>• Users registered with Google cannot login with password.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Other Information** | • The system supports "Ghi nhớ đăng nhập" option.<br>• Can alternatively log in with Google.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Assumptions**       | The User has stable internet connection.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |

| **Secondary Actors**  | Email Service                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Trigger**           | The Guest wants to create a new account to use the UniLife system.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Description**       | This Use Case allows the Guest to register a new account in the system. The registration process includes: entering personal information, sending an OTP code via email, and verifying the OTP to complete registration.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Preconditions**     | • The registration page is displayed.<br>• The Guest has a valid and active email.<br>• The Guest does not have an account in the system.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Postconditions**    | • A new account is created in the system with role "customer".<br>• Email is verified (emailVerified = true).<br>• Access token is created and saved.<br>• The User is redirected to the login page.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Normal Flow**       | 1. The Guest accesses the registration page.<br>2. The Guest enters full name in the "Họ và tên" field.<br>3. The Guest enters email in the "Email" field.<br>4. The Guest enters phone number in the "Số điện thoại" field.<br>5. The Guest enters password in the "Mật khẩu" field.<br>6. The Guest clicks the "Đăng ký" button.<br>7. The system validates the data.<br>8. The system checks that email and phone number do not exist.<br>9. The system generates a 6-digit OTP code and sends it to the email.<br>10. The system displays message "Đã gửi mã OTP!".<br>11. The system redirects to the OTP verification page.<br>12. The Guest enters the 6-digit OTP code received via email.<br>13. The system verifies the OTP code.<br>14. The system creates a new account.<br>15. The system displays message "Đăng ký thành công!".<br>16. The system redirects to the login page.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Alternative Flows** | **A. Email already in use (Step 8)**<br>A.1 The system detects that the email already exists in the system.<br>A.2 The system displays message "Email đã được sử dụng".<br>A.3 The Guest can edit the email and try again.<br>A.4 Return to Step 3.<br><br>**B. Phone number already in use (Step 8)**<br>B.1 The system detects that the phone number already exists.<br>B.2 The system displays message "Số điện thoại đã được sử dụng".<br>B.3 The Guest can edit the phone number and try again.<br>B.4 Return to Step 4.<br><br>**C. Invalid OTP code (Step 13)**<br>C.1 The entered OTP code is incorrect or has expired.<br>C.2 The system displays message "Xác thực OTP thất bại".<br>C.3 The system clears the entered OTP code.<br>C.4 The Guest can re-enter the OTP code.<br>C.5 Return to Step 12.<br><br>**D. Resend OTP code (Step 12)**<br>D.1 The Guest clicks "Gửi lại mã OTP" after countdown ends (60 seconds).<br>D.2 The system generates a new OTP code and sends it to the email.<br>D.3 The system resets the countdown to 60 seconds.<br>D.4 Return to Step 12.<br><br>**E. Password not long enough (Step 7)**<br>E.1 The entered password is less than 6 characters.<br>E.2 The system displays message "Mật khẩu phải có ít nhất 6 ký tự".<br>E.3 Return to Step 5.<br><br>**F. Guest already has account (Step 1)**<br>F.1 The Guest clicks "Đăng nhập ngay" link.<br>F.2 The system redirects to the login page.<br>F.3 End Use Case. |
| **Exceptions**        | **E. Unable to send OTP email (Step 9)**<br>E.1 The system encounters an error when sending OTP email.<br>E.2 The system displays message "Không thể gửi email OTP. Vui lòng thử lại sau".<br>E.3 End Use Case.<br><br>**F. Rate limit exceeded (Step 9)**<br>F.1 The Guest sends too many OTP requests in a short time.<br>F.2 The system displays message "Vui lòng đợi X giây trước khi gửi lại mã OTP".<br>F.3 The Guest must wait for the cooldown period.<br>F.4 Return to Step 6.<br><br>**G. Network connection lost (Step 6, Step 12)**<br>G.1 Network connection is interrupted.<br>G.2 The system displays network error message.<br>G.3 End Use Case.<br><br>**H. Unknown system error**<br>H.1 An unexpected system error occurs.<br>H.2 The system logs the error.<br>H.3 The system displays generic error message.<br>H.4 End Use Case.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Priority**          | High, Must Have                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Frequency of Use**  | Moderate                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Business Rules**    | • Email must be in valid format and not exist in the system.<br>• Phone number must not exist in the system.<br>• Password must be at least 6 characters.<br>• OTP code is valid for 5 minutes.<br>• OTP code consists of 6 digits.<br>• Must wait 60 seconds between OTP sends.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Other Information** | • Default role for new account is "customer".<br>• Supports pasting OTP code from clipboard.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Assumptions**       | • The Guest has access to email to receive OTP.<br>• Email service is functioning normally.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

## UC03 - Login with Google

| Section               | Content                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **UC ID and Name**    | UC03 Login with Google                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Created By**        | Le Thanh Tra                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Date Created**      | 26/01/2026                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Primary Actor**     | User/Guest                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Secondary Actors**  | Google OAuth Service                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Trigger**           | The User/Guest wants to quickly log in or register using a Google account.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Description**       | This Use Case allows the User/Guest to log in to the system using a Google account. If the User does not have an account, the system will automatically create a new account based on information from Google. If the User already has an account (registered with email), the system will link it with Google.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **Preconditions**     | • The login page is displayed.<br>• The User/Guest has a valid Google account.<br>• Google OAuth is properly configured in the system.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Postconditions**    | • The User is authenticated and logged into the system.<br>• The access token is saved to localStorage.<br>• User information is saved to localStorage.<br>• If new user, account is created with provider = "google".<br>• The User is redirected to the home page.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Normal Flow**       | 1. The User accesses the login page.<br>2. The User clicks the "Đăng nhập bằng Google" button.<br>3. The system displays Google OAuth popup.<br>4. The User selects a Google account to log in.<br>5. Google authenticates and returns ID Token.<br>6. The system sends ID Token to backend for verification.<br>7. The system verifies the Google ID Token.<br>8. The system checks the user in the database.<br>9. The system generates an access token and returns user information.<br>10. The system displays message "Đăng nhập thành công!".<br>11. The system redirects the user to the home page.                                                                                                                                                                                                                                                                                                                                             |
| **Alternative Flows** | **A. New user - No account (Step 8)**<br>A.1 The system cannot find user with email from Google.<br>A.2 The system creates a new account with information from Google (email, name, avatar).<br>A.3 The system sets provider = "google", emailVerified = true.<br>A.4 Continue to Step 9.<br><br>**B. User has local account (Step 8)**<br>B.1 The system finds user registered with email/password.<br>B.2 The system links account with Google (update provider = "google").<br>B.3 The system updates avatar if not set.<br>B.4 Continue to Step 9.<br><br>**C. User previously logged in with Google (Step 8)**<br>C.1 The system finds user with provider = "google".<br>C.2 The system updates lastLoginAt.<br>C.3 Continue to Step 9.<br><br>**D. User cancels Google login (Step 4)**<br>D.1 The User closes popup or clicks Cancel.<br>D.2 The system displays message "Không thể kết nối với Google. Vui lòng thử lại."<br>D.3 End Use Case. |
| **Exceptions**        | **E. Invalid Google ID Token (Step 7)**<br>E.1 Token from Google cannot be verified.<br>E.2 The system displays message "Invalid Google token".<br>E.3 End Use Case.<br><br>**F. Google does not provide email (Step 7)**<br>F.1 Token does not contain email information.<br>F.2 The system displays message "Email not provided by Google".<br>F.3 End Use Case.<br><br>**G. Network connection lost (Step 3, Step 6)**<br>G.1 Network connection is interrupted.<br>G.2 The system displays network error message.<br>G.3 End Use Case.<br><br>**H. Unknown system error**<br>H.1 An unexpected system error occurs.<br>H.2 The system logs the error.<br>H.3 The system displays generic error message.<br>H.4 End Use Case.                                                                                                                                                                                                                       |
| **Priority**          | High, Should Have                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Frequency of Use**  | Frequent                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Business Rules**    | • Email from Google is automatically verified (emailVerified = true).<br>• Google account will not have password (password = null).<br>• Default role is "customer" for new accounts.<br>• Display name is taken from Google profile or created from email.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Other Information** | • Avatar is taken from Google profile if user doesn't have one.<br>• OTP verification is not required when registering with Google.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Assumptions**       | • Google OAuth service is functioning normally.<br>• The User allows the application to access basic information.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

## UC04 - Logout

| Section               | Content                                                                                                                                                                                                                                                                                                                                                                                   |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **UC ID and Name**    | UC04 Logout                                                                                                                                                                                                                                                                                                                                                                               |
| **Created By**        | Le Thanh Tra                                                                                                                                                                                                                                                                                                                                                                              |
| **Date Created**      | 26/01/2026                                                                                                                                                                                                                                                                                                                                                                                |
| **Primary Actor**     | User                                                                                                                                                                                                                                                                                                                                                                                      |
| **Secondary Actors**  | None                                                                                                                                                                                                                                                                                                                                                                                      |
| **Trigger**           | The User wants to log out of the system.                                                                                                                                                                                                                                                                                                                                                  |
| **Description**       | This Use Case allows the User to log out of the system. The current access token will be invalidated (blacklisted) and user data will be removed from localStorage.                                                                                                                                                                                                                       |
| **Preconditions**     | • The User is logged into the system.<br>• A valid access token is stored in localStorage.                                                                                                                                                                                                                                                                                                |
| **Postconditions**    | • The access token is added to the blacklist.<br>• The access token is removed from localStorage.<br>• User information is removed from localStorage.<br>• The User is redirected to the login page.                                                                                                                                                                                      |
| **Normal Flow**       | 1. The User clicks on the account menu or logout button.<br>2. The User confirms wanting to log out.<br>3. The system sends logout request to backend.<br>4. Backend adds the access token to blacklist.<br>5. The system removes the access token from localStorage.<br>6. The system removes user information from localStorage.<br>7. The system redirects the user to the login page. |
| **Alternative Flows** | **A. Logout API fails (Step 3)**<br>A.1 Logout request to backend is unsuccessful.<br>A.2 The system still continues to clear local data.<br>A.3 Continue to Step 5.                                                                                                                                                                                                                      |
| **Exceptions**        | **E. Network connection lost (Step 3)**<br>E.1 Network connection is interrupted.<br>E.2 The system still clears local data and logs out user.<br>E.3 Continue to Step 5.<br><br>**F. Unknown system error (Step 3)**<br>F.1 An unexpected system error occurs.<br>F.2 The system logs the error.<br>F.3 The system still continues to log out on client side.<br>F.4 Continue to Step 5. |
| **Priority**          | High, Must Have                                                                                                                                                                                                                                                                                                                                                                           |
| **Frequency of Use**  | Moderate                                                                                                                                                                                                                                                                                                                                                                                  |
| **Business Rules**    | • Blacklisted tokens cannot be reused for authentication.<br>• Local data is always cleared even if API has errors.                                                                                                                                                                                                                                                                       |
| **Other Information** | • Token blacklist can use Redis in production.<br>• Currently uses in-memory Set for blacklist.                                                                                                                                                                                                                                                                                           |
| **Assumptions**       | The User has access to the logout button when logged in.                                                                                                                                                                                                                                                                                                                                  |
