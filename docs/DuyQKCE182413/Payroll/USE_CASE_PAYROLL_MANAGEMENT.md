| **Description**       | This Use Case allows Users to view a list of all payroll periods belonging to their canteen. | **Normal Flow**       | 1. User accesses the "Bảng lương" page under "Quản lý lương" menu.<br>2. System sends GET request to API `/api/payrolls?canteenId={canteenId}`.<br>3. Backend authenticates JWT token via `protect` middleware.<br>4. Backend checks role via `restrictTo("admin", "canteen_owner", "manager")` middleware.<br>5. Backend queries payrolls list filtered by `canteenId` from `req.user`.<br>6. Backend returns data including: payroll details, populated canteenId, createdBy, approvedBy, paidBy.<br>7. Frontend displays table with columns:<br>&nbsp;&nbsp;&nbsp;- Kỳ lương (Period: DD/MM/YYYY - DD/MM/YYYY)<br>&nbsp;&nbsp;&nbsp;- Nhân viên (Staff count)<br>&nbsp;&nbsp;&nbsp;- Tổng giờ (Total hours)<br>&nbsp;&nbsp;&nbsp;- Tổng lương (Total amount in VND)<br>&nbsp;&nbsp;&nbsp;- Thưởng (Bonus in VND)<br>&nbsp;&nbsp;&nbsp;- Khấu trừ (Deduction in VND)<br>&nbsp;&nbsp;&nbsp;- Trạng thái (Status: Draft/Calculated/Approved/Paid with colored Tags)<br>&nbsp;&nbsp;&nbsp;- Thao tác (Actions: View/Approve/Pay/Delete buttons)<br>8. Display results count "Tổng {count} kỳ lương". |
| **Alternative Flows** | **A. Empty list (Step 6)**<br>A.1 Backend returns empty data array (no payroll exists).<br>A.2 Frontend displays Alert message "Chưa có kỳ lương nào. Nhấn 'Tạo bảng lương mới' để bắt đầu."<br>A.3 End Use Case.<br><br>**B. | **Exceptions**        | **E. Error loading data (Step 2-5)**<br>E.1 Request fails (network error, server error).<br>E.2 Frontend displays error message "Không thể tải danh sách bảng lương".<br>E.3 End Use Case.<br><br>**F. Unauthorized access (Step 4)**<br>F.1 User has inappropriate role (e.g., staff, customer).<br>F.2 Backend returns 403 Forbidden error.<br>F.3 Frontend redirects to appropriate page.<br>F.4 End Use Case.<br><br>**G. Token expired (Step 3)**<br>G.1 JWT token has expired or is blacklisted.<br>G.2 Backend returns 401 Unauthorized error.<br>G.3 Frontend handles redirect to login page.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Priority**          | High, Must Have                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

| **Other Information** | • Frontend uses Ant Design Table component with rowKey as `_id`.<br>• Amount fields are formatted as VND currency using formatCurrency function.<br>• Date fields are formatted using dayjs in DD/MM/YYYY format.<br>• Actions column displays conditional buttons based on status:<br>&nbsp;&nbsp;- View: always available<br>&nbsp;&nbsp;- Approve: only for calculated status<br>&nbsp;&nbsp;- Pay: only for approved status<br>&nbsp;&nbsp;- Delete: only for draft/calculated status (admin/manager only)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Assumptions**       | • User has stable network connection.<br>• Backend service is operating normally.<br>• User's canteen has been properly set up.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
