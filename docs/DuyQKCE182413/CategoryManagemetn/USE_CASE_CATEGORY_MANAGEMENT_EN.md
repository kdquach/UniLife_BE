| **Secondary Actors**  | None                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Trigger**           | User accesses the "Ingredient Categories" page on Dashboard to view the list of ingredient categories.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Description**       | This Use Case allows Users to view a list of ingredient categories belonging to their canteen. The list is displayed in a table with pagination, including information: category name, description, last updated date, and status.                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Preconditions**     | • User has logged into the Dashboard system.<br>• User has role as admin, manager, or staff.<br>• User is assigned to a canteen (has canteenId).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Postconditions**    | • The list of ingredient categories is displayed in the table.<br>• Pagination information (current page, total records) is updated.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Normal Flow**       | 1. User accesses the "Ingredient Categories" page on Dashboard.<br>2. System sends GET request to API `/api/ingredient-categories?page=1&limit=10`.<br>3. Backend authenticates token (if available) and retrieves `canteenId` from user.<br>4. Backend queries the list of ingredient categories by `canteenId` with pagination.<br>5. Backend returns the data list along with pagination information (page, limit, total).<br>6. Frontend displays data table with columns: Category Name, Description, Updated (format DD/MM/YYYY HH:mm), Status (Tag "Active"), Actions.<br>7. Display pagination information "Total X ingredient categories" below the table. |
| **Alternative Flows** | **A. Change page (Step 7)**<br>A.1 User clicks to change page or modifies records per page (pageSize).<br>A.2 System sends GET request with new page and limit params.<br>A.3 Backend returns new page data.<br>A.4 Frontend updates table and pagination.<br>A.5 Return to Step 6.<br><br>**B. Empty list (Step 5)**<br>B.1 Backend returns empty data array (no ingredient categories exist).<br>B.2 Frontend displays empty table with Ant Design Table default message.                                                                                                                                                                                         |
| **Exceptions**        | **E. Error loading data (Step 2-5)**<br>E.1 Request fails (network error, server error).<br>E.2 Frontend displays error message "Cannot load ingredient categories list".<br>E.3 End Use Case.<br><br>**F. Token expired (Step 3)**<br>F.1 JWT token has expired or is blacklisted.<br>F.2 Backend returns 401 Unauthorized error.<br>F.3 Frontend handles redirect to login page.                                                                                                                                                                                                                                                                                  |
| **Priority**          | High, Must Have                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Frequency of Use**  | Very frequent                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Business Rules**    | • Data is filtered by `canteenId` of the logged-in user, ensuring data isolation between canteens.<br>• Default pagination: page = 1, limit = 10.<br>• User can change the number of records per page (showSizeChanger).<br>• GET API is public but controller reads `canteenId` from user (optional) to filter data.                                                                                                                                                                                                                                                                                                                                               |
| **Other Information** | • Frontend uses Ant Design Table component with rowKey as `_id`.<br>• "Actions" column displays Dropdown with 3 options: View, Edit, Delete.<br>• Updated date is formatted using dayjs in DD/MM/YYYY HH:mm format.                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Assumptions**       | • User has stable network connection.<br>• Backend service is operating normally.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |

| **Normal Flow**       | 1. User clicks the "Create New" button at the top right corner of the page.<br>2. User enters description in "Description" field (optional, textarea).<br>5. User clicks "Create" button.<br>6. Frontend validates form (checks "Category Name" field is not empty).<br>7. Frontend sends POST request to API `/api/ingredient-categories` with body `{ name, description }`.<br>8. Backend middleware `protect` authenticates JWT token.<br>9. Backend middleware `restrictTo` checks role (admin, manager, staff).<br>10. Backend controller gets `canteenId` from `req.user` and calls service.<br>11. Backend service checks category name is not duplicate (case-insensitive) within same canteen.<br>12. Backend creates new record in database with `{ canteenId, name, description }`.<br>13. Backend returns 201 response with data of newly created category.<br>14. Frontend displays message "Ingredient category created".<br>15. Frontend closes Modal and calls fetchList() to update the list. |

Network or server error (Step 7)**<br>G.1 Request fails due to network error or server error.<br>G.2 Frontend displays message "Cannot save data".<br>G.3 End Use Case.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |

| **Other Information** | • Form uses Ant Design Form component with "vertical" layout.<br>• Form has 2 fields: name (Input) and description (TextArea, 3 rows).<br>• requiredMark is hidden (requiredMark={false}).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

## General Comparison between Ingredient Category and Product Category

| Criteria                  | Ingredient Category (UC17)                           | Product Category (UC18)                                                        |
| ------------------------- | ---------------------------------------------------- | ------------------------------------------------------------------------------ |
| **Backend Authorization** | Role-based: admin, manager, staff (`restrictTo`)     | Permission-based: PRODUCT\_\*\_READ/CREATE/UPDATE/DELETE (`requirePermission`) |
| **GET API**               | Public (no authentication required)                  | Protected (requires authentication + permission)                               |
| **Form Fields**           | name (required), description (optional)              | name (required, min 2), description (optional, max 500), isActive (Switch)     |
| **Status Display**        | Always shows "Active" Tag (hardcoded)                | Shows actual status from `isActive` ("Active" / "Inactive")                    |
| **Table Sort/Filter**     | Not supported                                        | Supports sort (name, created date) and filter (status) on client-side          |
| **Detail Modal**          | Only close button (footer=null)                      | Has 2 buttons: "Close" and "Edit"                                              |
| **Table Columns**         | Category Name, Description, Updated, Status, Actions | Category Name, Description, Status, Created Date, Actions                      |
| **Dropdown Trigger Icon** | more_horiz (⋯)                                       | more_vert (⋮)                                                                  |
| **Create Button Text**    | "Create New"                                         | "Add Category"                                                                 |
